# Somraj's Portfolio

A personal portfolio for Somraj Bhattacharya, a first-year B.Tech student exploring Genetics and Artificial Intelligence.

## About the site

This is a responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. It is intentionally simple, personal, and easy to update as Somraj's skills and projects grow.

## Add the profile photo

Place the photo at `assets/profile.jpg`, then replace the `.portrait-placeholder` block in `index.html` with:

```html
<img class="profile-photo" src="assets/profile.jpg" alt="Somraj Bhattacharya" />
```

The photo slot is designed for a clear portrait without headphones, as requested.
